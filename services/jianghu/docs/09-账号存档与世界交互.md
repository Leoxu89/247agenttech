# v4：账号、可靠存档、世界地图与生死界面

日期：2026-10-20。用户指定正式后端使用自己已有的 Cloudflare 账号；前端继续 247agenttech.com/jianghu/ 与 GitHub Pages。

## 交付行为

- 首屏手动创建角色或用户名/密码登录，中文姓名、性别、出生地区可选。Web 密码不用于原版英文角色密码；服务端分配独立原版身份。旧游客本机存档继续保留。
- 手动存档、20 秒自动快照、每次安全移动前的路径检查点。界面区分本机已存与云端已同步；失败不假装成功，不清除本机进度。重新登录下载云端最新存档，并读取手动/检查点历史，支持其他设备续玩。
- 直接调用原版角色 save 方法，绕开 `save` 指令的 30 秒限制，保留原版逻辑。另记录普通物品、数量、容器、装备；载入原版角色文件后还原行囊与准确房间。交战、昏迷、死亡、临时船只中不覆盖安全快照。
- 云端以账号归属读取，修订号冲突返回 409。恢复写成新版本，保留可回看的历史。密码 PBKDF2 + 随机 salt + 服务端 pepper；存档与原版身份 AES-GCM 加密。秘密只配置于后端环境。
- 世界地图包括提取的全部 5650 场景，支持拖动、双指缩放、缩放按钮、定位、全图、地点/地区搜索、点击选定实际场景寻路；地图是原坐标及道路的示意，不是假设精确地形。
- 依据原版 RIVER 的实际目标增加渡船路线：暂停、呼船、登船、等候、下船、到岸后继续。全真敲门后仍需守卫允许。源文件中的明确机关参数可点选；海港问船与付款、桃花岛掌舵与眺望均提供按钮，原版金钱/知识条件不变。谜题条件、迷阵、未知通道不会凭空添加捷径。
- 遭攻击自动进入战斗界面，双方血量与内力、实时原版文字、普通迎战、已激发武学招式、按实际出口逃跑、恢复、行囊和体验补给。对已经攻击玩家的敌人建立反击关系，伤害与轮次仍由原版处理。
- 昏迷专页；死亡后暂停引擎，显示死亡原因及临终记录，可恢复前一路径检查点或最近手动存档。此前没有安全存档的旧角色会明确提示，无虚构复活记录。
- 输入框使用至少 16px 字号，应用和弹层跟随 visualViewport，关闭输入会收起焦点。终端不再自动抢焦点；不因键盘变矮而切换原始终端布局。

## 验证与边界

真实 WASM：创建角色、重复小额补给、命名出口移动、快速连续检查点、全新引擎读取原版角色/房间/普通物品；原版河岸呼船、动态渡船、35 秒航行、下船；野狗主动攻击、反击、死亡识别与安全存档防覆盖。

数据库：真实 SQLite 的账号隔离、密码错误、越权访问/恢复拦截、加密、修订号冲突和历史恢复。独立在线联调 D1 已跑通注册、登录、账号历史和注销。所有者已完成官方 OAuth 授权，正式 Worker 与 D1 已部署到其账号。正式接口已验证注册/登录、上传/下载、冲突409与跨会话保留。GitHub Pages 版本 5698430 已成功发布，线上浏览器创建云舟、添加普通火折、客寓至马厩移动与安全检查点/手动同步均通过。

浏览器：手动注册/重新登录、云端保存、位置与历史恢复；世界地图缩放、地点选路；390px 窄屏及420px可用高度下输入面板无横向溢出、关闭可见。实际 iPhone 系统键盘仍需用户真机复核。战斗与死亡界面以真实引擎记录的状态作独立版式检查，测试夹具未打包进正式游戏。

本版仍为各浏览器独立运行的单人世界，数据库保存账号与角色进度。尚不提供多人同场、邮件联机、找回密码、所有机关/全地图逐项验收。
