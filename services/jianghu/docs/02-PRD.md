# PRD：侠客行 100 手机网页版

版本 v0.1；日期 2026-10-19；以用户最新指示为准：暂不采用炎黄，优先跑通原版并快速交付。

## 目标

让用户通过浏览器进入真实侠客行 100，在手机上少输指令即可探索和操作。优先复用已有世界，不重写剧情、不重构门派、不替换战斗数值。

## 首版需求

| 优先级 | 需求 | 验收 |
| --- | --- | --- |
| P0 | 原版引擎与世界 | 创建角色，look、hp、移动有真实响应 |
| P0 | 手机界面 | 窄屏可见输出、方向键、指令输入和发送 |
| P0 | 常用动作 | 行走、修行、交互、人物分类；缺参数的动作允许编辑后发送 |
| P0 | 本机存档 | 保存后刷新，重新登录能恢复角色 |
| P1 | 试玩入口 | 自动完成原版游客注册，支持游客续玩 |
| P1 | 新手指南 | 解释创建、目标 ID、保存及单机范围 |

## 本版不包含

2D 场景、多人服务器、跨设备同步、全门派逐派验收、剧情改写、AI 对话、付费系统。门派以原版实现为准，不宣称全部经过实测。

## 关键约束

原版源码 checkout 保持不变；网页适配独立存放。使用原版指令与校验；按钮不绕过拜师、金钱、战斗和属性限制。存档按浏览器和网址隔离；切换本地预览到线上链接不会自动迁移。

## 下一轮评审

用户先评估手机阅读、方向按钮和操作便利性。确认后再选：改善目标选择、门派导航，或增加 2D 表现；不在本轮自行扩大范围。

## v2：手机点选优先（2026-10-20）

用户确认推进：出口必须显示目的地；人物直接点选；身体状态、人物档案和行囊改为移动端面板。常用流程无需输入英文 ID。具体需求、边界与验收见《07-手机点选界面.md》。自由文本终端仅作为特殊指令备用入口。

## v3：地图、寻路与新手补给（2026-10-20）

新增实时道路图、门派/师承目的地、可暂停自动寻路和不限次数的少量补给。修正 iPhone 截图中名称与布局问题。实现、参数和特殊路段限制见《08-实时地图与天神体验.md》。

## v4：可靠云端存档与全程点选（2026-10-20）

本节覆盖早期“本机存档、不包含跨设备同步”的边界：新增手动账号、Cloudflare Workers + D1、修订号冲突保护、手动/自动/移动前检查点；世界地图支持缩放与地点选路；渡船和机关分步按钮；战斗和死亡专页；键盘布局修复。仍不包含多人世界，原始源码保持不变。详见《09-账号存档与世界交互.md》。所有者 Cloudflare 授权是正式上线前置条件。
