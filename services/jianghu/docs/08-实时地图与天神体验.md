# 实时地图、自动寻路与天神体验 v3

日期：2026-10-20；发布地址：https://247agenttech.com/jianghu/

## 本轮需求

- 门派和学艺地点可在地图中查找、点选，预览路线后自动行走。
- 实时标记当前场景与区域，显示当前出口及再往前的道路。
- 更多菜单增加天神体验：少量食水、气血和内力，可不限次数点击。
- 修复用户 iPhone 截图里的横向滚动条、动作结果遮挡按钮、武学名称显示英文 ID、信箱把整段指令文档当简介的问题。

## 实现与边界

世界索引由固定原版源码提取，5650 个场景、11606 条有向出口连接。列出 31 个门派、师承分支和新手学艺目的地，不等于 31 个独立开放门派。门派目标采用真实房间名；部分目标是公共入口或山脚，说明中标注后续需过关。地图是道路/位置示意，不是按现实比例绘制的中国地图。

实时状态来自实际游戏中的角色环境，首跳与邻接场景出口动态补正静态索引。附近地图中心明确标“你在这里”，列出下一场景的各个出口。门派图显示相对位置并标出角色的场景/区域位置。

寻路用有向图最短路径；逐步通过原版方向指令执行并等待实际场景变化。支持暂停、重规划继续、取消。门关闭时尝试原版开门指令；4 秒未通行、位置偏离、交战、忙碌、断线或退出页面时暂停。不会绕过守卫和门派条件，不自动拜师。静态连通不表示所有角色都能通过。桃花岛、神龙岛、燕子坞等渡船或特殊路段目前不全自动，已有确定接引处的可先导航至接引处；白驼山等迷阵路段仍需手动。没有凭空添加连接。

天神体验是本轮明确授权的新测试辅助，和常规原版动作分开：每次食水 +30、气血 +20（伤势修复至多 10）、内力 +10，当前容量封顶，不限点击次数；无内功修为时内力可临时补到 30，不抬高 max_neili；可备一支原版火折解决夜间视野。不修改经验、技能、潜能或角色位置，不复活亡魂。

补给修改仍在适配 overlay 内，原版 checkout 保持干净。继续使用原来的 IndexedDB 和存档格式，无服务器数据库。
