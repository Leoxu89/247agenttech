# 手机点选界面 v2

日期：2026-10-20。目标网址：https://247agenttech.com/jianghu/

## 需求与实现

- 场景出口显示方向及真实目的地名称；只列当前房间实际出口，关闭的门先提供开门动作。
- 列出可见人物，点选后查看、打听、拜师、请教、交付物品或切磋；打听列出原版 inquiry 主题。
- 地上物品可查看、拾取；行囊按原版物品属性提供吃喝、穿戴、装备、阅读、放下。
- 气血、内力、食水常驻；人物档案使用属性卡片；武学按实际已学技能列出，提供请教和激发、练习操作。
- 单次查看与打听使用本次回应面板；历史记录和指令终端收进更多菜单。
- 登录仍使用原版流程，游客可一键创建和续玩；少数特殊谜题和自由文本交流暂保留备用输入。

## 架构与原版边界

原版 checkout 无修改。打包新增 `overlays/adm/daemons/pocketui.lpc`，并追加打包版 preload；守护进程通过官方 js_export 提供只读结构化快照。前端 `pocket.js` 请求快照，所有动作通过现有 Telnet 通道执行原版命令，拜师、金钱、忙碌和战斗限制继续生效。

出口名来自相邻房间 short；人物过滤可见性，名称与目标 ID 尊重伪装。夜晚室外无照明时不显示人物物品。交易、学艺按钮不保证原版条件已经满足，拒绝原因在动作反馈中显示。

仍使用原来的 IndexedDB 名称与存档文件格式。没有添加云数据库或网络账号同步。

## 构建与验收

1. `python3 jianghu-web/scripts/build.py` 打包原版与只读覆盖。
2. Node 运行 `jianghu-web/scripts/engine-smoke.cjs`：真实 WASM 注册、结构化状态、点击所用出口指令与目标名一致、保存、全新引擎恢复并登录。
3. `python3 jianghu-web/scripts/prepare-github.py` 产生 gzip 静态包；保留官方驱动不变。
4. 浏览器 390×844 验收：游客续玩、带目的地的出口、点人物打听、本次对话面板、属性卡片、行囊穿戴；另检查窄屏布局。
5. 发布仅修改 GitHub 仓库 jianghu 目录，基于最新 main 树，不覆盖其他项目。

本轮不做所有门派和任务逐项验收；复杂自定义 NPC 动作仍可能需要备用终端。存档导出下载未重新执行测试，沿用现有实现。
