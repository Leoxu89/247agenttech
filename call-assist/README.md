# Call Assist — phone preview

Open https://247agenttech.com/call-assist/ in iPhone Safari. Try the sample, edit a transcript line, end the session and export notes. Start a new session to test the microphone in Australian English.

This GitHub Pages preview runs local coaching rules entirely in the browser. No AI, Dropbox or REA feed is connected. Transcript is held in the tab until exported; it is not uploaded by the app. Browser speech recognition may process audio with its provider. No automatic speaker identification or background listening.

The source/ directory contains the reproducible Node project and deployment instructions.
