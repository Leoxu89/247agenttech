# Floating City: 40 Days · 浮城四十日

Play: https://247agenttech.com/40-days/

A standalone Chinese/English trading game across ten world cities. Open index.html or floating_city_40_days.html to play. No dependencies or build step.

Includes downloadable JSON saves, property upgrades, dice with fictional game money, and a leaderboard stored in each browser. Saves can be imported on other devices; leaderboard records do not synchronize online.

No open-source license has been granted.
