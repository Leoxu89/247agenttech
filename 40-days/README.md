# Floating City: 40 Days · 浮城四十日

Play: https://247agenttech.com/40-days/

A bilingual trading game across ten world cities. Standalone HTML, with no game build step.

## Mobile controls

Tap the compact top status bar for detailed balances, health, storage and actions. Open ☰ for save/load/new game. Buy, sell and travel from the main screen without page scrolling; short screens paginate products. Expanded panels and dialogs scroll internally when needed.

## Saves and records

Save file downloads JSON; Load file imports it later. Browser backups and older Device records remain local.

The World leaderboard is shared across visitors and stored in a hosted D1 database. Finish a run and publish your name and net worth; failed submissions can be retried. The board displays the highest 100 while retaining all submitted records. These are community-submitted scores, not verified competition results.
