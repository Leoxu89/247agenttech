# 侠客行100 · 掌上江湖

访问：https://247agenttech.com/jianghu/

游戏由 GitHub Pages 提供，FluffOS WASM 在浏览器内运行；不连接 ChatGPT，不使用云端数据库。角色存档保存在当前浏览器的 IndexedDB。

点击“进入 / 继续江湖”创建或继续游客角色；右上角“新手指南与存档管理”中可导出、导入存档。更换域名不会自动复制浏览器数据。

上游源码：https://github.com/fluffos/xkx100
固定提交：c1b87db0014c85514e053b2a149a2efccb9914e3
官方驱动：FluffOS v2026.1001.0

上游游戏源码 checkout 保持原样。打包时配置 mudlib 路径为 /mudlib，并向 preload 追加pocketui 适配守护进程，提供场景、出口目的地、可见人物、物品、状态和武学数据。行走、学艺、交易等仍由原版指令执行；天神体验是用户主动选择的少量本机补给。点选手机界面在 pocket.js、pocket.css，基础登录与存档适配在 mobile.js、mobile.css、mudlib.js；游戏文件列表见 mudlib-manifest.json。

两个大资源使用预压缩 gzip：mudlib.data.gz、fluffos.wasm.gz，由浏览器解压；需要支持 WebAssembly、IndexedDB 和 DecompressionStream 的现代浏览器。静态文件合计约8.3MB，解压后原始包约28.5MB。

个人测试版：无多人联机、无跨设备自动同步；任务临时状态和NPC世界状态不做完整快照，出生点恢复沿用原版规则。

## v2 手机操作（2026-10-20）

出口显示实际目的地；人物与物品可点选操作。气血、内力、食水常驻；行囊、武学、人物档案使用独立面板。原版终端作为更多菜单内的备用入口。夜晚室外需要照明才能显示人物物品，仍按原版规则。

## v3 地图与新手体验（2026-10-20）

底部地图显示实时位置与附近出口，门派图提供 31 个门派/师承入口及新手学艺目的地。静态索引含 5650 个场景、11606 条出口；当前位置与邻接出口以实际内核状态修正。自动行走逐步确认位置，遇到阻碍暂停，不传送或自动拜师。渡船、迷阵和机关等特殊路段需手动处理，可先导航至已知码头/接引处。

更多菜单提供天神体验：食物/饮水每次 +30、气血 +20、内力 +10，不限次数，容量封顶；无内功时临时内力容量 30，不提高修为，另可备一支原版火折。不会增加经验、武学、潜能。中文武学名优先沿用原版词典，缺失时采用源码中的技能标题。
